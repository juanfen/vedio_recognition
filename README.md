# 动作识别模型项目

一个基于PyTorch的动作识别模型实现，包含多种先进的深度学习架构。

## 📋 项目概述

本项目实现了多种动作识别模型，可用于视频分类、行为识别等计算机视觉任务。支持从2D到3D的多种卷积架构，适用于不同的计算资源和精度需求。

## 🚀 模型列表

### 1. C3D (3D Convolutional Networks)
**特点**：
- 使用3D卷积核直接处理视频时序信息
- 端到端训练，无需光流等额外特征
- 在体育动作识别等任务中表现良好

**适用场景**：短时序动作识别，计算资源充足的情况

### 2. CNN-LSTM
**特点**：
- CNN提取空间特征 + LSTM建模时序依赖
- 结合了2DCNN的计算效率和LSTM的时序建模能力
- 灵活性强，可替换不同的CNN backbone

**适用场景**：长视频序列，对计算效率要求较高的场景

### 3. SlowFast
**特点**：
- 双路径架构：Slow路径处理低帧率高分辨率，Fast路径处理高帧率低分辨率
- 横向连接实现多尺度特征融合
- 在速度和精度间取得良好平衡

**适用场景**：需要同时捕捉细节动作和整体运动模式的复杂场景

### 4. X3D
**特点**：
- 通过网络扩展（expansion）策略逐步增加模型容量
- 提供了从微型到大型的多种配置
- 在计算效率和精度方面达到state-of-the-art

**适用场景**：移动端部署到服务器端推理的全系列需求
